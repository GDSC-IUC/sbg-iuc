# AWS SCD IUC 2026

Bienvenue dans le dépôt du projet **AWS SCD IUC 2026**. Ce projet est une landing page moderne et interactive développée pour promouvoir et gérer l'événement AWS SCD à l'IUC pour l'édition 2026.

## 🚀 Fonctionnalités

La page intègre plusieurs sections clés pour offrir une expérience utilisateur complète :
- **Bannière de compte à rebours**
- **Navigation (TopNav) & Footer**
- **Section Héro (HeroSection)**
- **À propos (AboutSection)**
- **Mission (MissionSection)**
- **Tuiles d'ambiance (AtmosphereTiles)**
- **Programme de l'événement (ProgrammeSection)**
- **Intervenants et Conférences (SpeakersTalkSection)**
- **L'équipe (TeamSection)**
- **Sponsors (SponsoringSection)**
- **Lieu (VenueSection)**
- **Inscription & FAQ (RegistrationFAQ)**

## 🛠️ Stack Technique

Ce projet est développé avec des technologies modernes pour garantir des performances optimales et un design premium :
- **Framework :** [Next.js 15](https://nextjs.org/)
- **Librairie UI :** [React 19](https://react.dev/)
- **Styling :** [Tailwind CSS](https://tailwindcss.com/)
- **Composants d'interface :** [Radix UI](https://www.radix-ui.com/) (Accordion, Dialog, Navigation Menu)
- **Icônes :** [Lucide React](https://lucide.dev/)
- **Langage :** [TypeScript](https://www.typescriptlang.org/)

## 📦 Installation et Lancement local

### Prérequis
Assurez-vous d'avoir [Node.js](https://nodejs.org/) installé sur votre machine.

### Étapes

1. Clonez ce dépôt.
2. Installez les dépendances :
   ```bash
   npm install
   # ou
   yarn install
   # ou
   pnpm install
   ```

3. Lancez le serveur de développement :
   ```bash
   npm run dev
   # ou
   yarn dev
   # ou
   pnpm dev
   ```

4. Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur pour voir le résultat.

## 📁 Structure du projet

- `/app` : Contient les pages de l'application (Next.js App Router).
- `/components` : Composants réutilisables organisés par dossiers (`/sections`, `/layout`, etc.).
- `/public` : Fichiers statiques, images et assets.
